# NEON RUSH — Официальный сайт группы

Современный адаптивный сайт музыкальной группы в жанре альтернативный рок / поп-панк.

## Стек

- React 19
- Vite 8
- React Router 7
- CSS Modules
- JavaScript (без TypeScript)

## Запуск

**Важно:** сайт нельзя открывать двойным щелчком по `index.html`. Нужен запущенный сервер.

### Вариант 1 — терминал (рекомендуется)

```bash
npm install
npm run start
```

Окно терминала **не закрывайте** — пока оно открыто, работает сайт.

Адрес в браузере: **http://127.0.0.1:5173/**

### Вариант 2 — Windows

Дважды щёлкните `start-dev.bat` в папке проекта. Не закрывайте чёрное окно, пока смотрите сайт.

### Ошибка «Port 5173 is already in use»

Сервер уже запущен в другом окне терминала — откройте **http://127.0.0.1:5173/** в браузере.

Если нужно перезапустить:

1. Закройте старое окно терминала с Vite, **или**
2. Дважды щёлкните `stop-dev.bat`, затем снова `npm run dev`

Vite сам подберёт свободный порт (5174, 5175…), если 5173 занят — смотрите адрес в терминале после `ready`.

### Сборка без dev-сервера

```bash
npm run build
npm run preview
```

Откроется http://127.0.0.1:4173/

## Структура

```
src/
├── components/   # Переиспользуемые UI-компоненты
├── pages/        # Страницы приложения
├── data/         # Моковые данные (группа, альбомы, концерты, галерея)
├── styles/       # Глобальные стили и CSS-переменные
├── hooks/        # Кастомные хуки
└── assets/       # Локальные ассеты
```

## Страницы

- **/** — Главная (hero, о группе, релиз, концерты, соцсети)
- **/music** — Дискография
- **/music/:id** — Страница альбома (треклист, тексты, YouTube)
- **/concerts** — Расписание с фильтром по городам
- **/gallery** — Фотогалерея с модальным окном
- **/contacts** — Форма обратной связи

## Данные

Все контентные данные в `src/data/`. Замените моки на реальные фото, ссылки и тексты группы.
